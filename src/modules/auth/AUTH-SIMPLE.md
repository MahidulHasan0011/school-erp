# 🎢 Auth Module — একদম সহজ ভাষায় (গল্পের মতো)

> ভাবো, তুমি একটা বড় **থিম পার্কে (school ERP)** গেছ। ভেতরে অনেক রাইড আছে।
> কিন্তু যেকেউ ঢুকে যেকোনো রাইডে চড়তে পারবে না। এটাই Auth-এর কাজ। 🎡

---

## 🎟️ ১. টিকিট কাউন্টার = **Login**

তুমি কাউন্টারে গিয়ে বললে: **"আমি রহিম, আমার পাসওয়ার্ড ১২৩৪।"**

```
POST /auth/login   { email, password }
```

কাউন্টারের লোক (AuthService) চেক করল:
- নাম-পাসওয়ার্ড ঠিক আছে? ✅
- হ্যাঁ! তাহলে তোমাকে একটা **হাতের ব্যান্ড (token)** পরিয়ে দিল 🎗️

এই ব্যান্ডের গায়ে লেখা: *"এ হলো রহিম, ও VIP রাইডে চড়তে পারবে।"*

> ❌ পাসওয়ার্ড ভুল হলে? কাউন্টার বলবে "যাও ভাগো!" (401 error)

---

## 🎗️ ২. হাতের ব্যান্ড = **Token (JWT)**

এই ব্যান্ডটা জাদুর। এর গায়ে **সব লেখা আছে**:

```
তোমার নাম: রহিম
তুমি কী কী পারবে: VIP রাইড, খাবার
তোমার সিরিয়াল নম্বর (sid): #7788
```

তাই প্রতিটা রাইডে গার্ডকে শুধু ব্যান্ড দেখালেই হয় — বারবার কাউন্টারে দৌড়াতে হয় না। এটাকে বলে **stateless** (ব্যান্ড নিজেই সব বলে দেয়)।

**দুই রকম ব্যান্ড:**
| ব্যান্ড | কতক্ষণ টেকে | কাজ |
|--------|-------------|-----|
| 🎗️ Access | ছোট (১ দিন) | রাইডে চড়তে এটা দেখাও |
| 🔄 Refresh | বড় (৭ দিন) | পুরনো ব্যান্ড ছিঁড়ে গেলে নতুন নিতে |

---

## 💂 ৩. রাইডের গার্ড = **JwtAuthGuard**

তুমি VIP রাইডে গেলে। গার্ড দাঁড়িয়ে:

```
@UseGuards(JwtAuthGuard)   ← এই গার্ড দরজায় দাঁড়ানো
```

গার্ড বলে: **"ব্যান্ড দেখাও!"**
- ব্যান্ড নেই? → ঢুকতে দেবে না ❌ (401)
- ব্যান্ড আছে? → গার্ড ব্যান্ডটা ভালো করে দেখে (আসল না নকল?)

কিন্তু মজার ব্যাপার — গার্ড নিজে বেশি কিছু জানে না। ও একজন **এক্সপার্টকে** ডাকে ব্যান্ড পরীক্ষা করাতে। সেই এক্সপার্ট = **JwtStrategy**।

---

## 🔍 ৪. ব্যান্ড-পরীক্ষক = **JwtStrategy**

এক্সপার্ট ৩টা জিনিস চেক করে:

1. **ব্যান্ডটা আসল তো?** (জাদুর সিল/signature ঠিক আছে?)
2. **মেয়াদ শেষ হয়ে যায়নি তো?** (তারিখ চেক)
3. **সিরিয়াল #7788 কি এখনো খাতায় আছে?** ← এটাই সবচেয়ে জরুরি!

তারপর বলে: *"হ্যাঁ, এ রহিম, ঢুকতে দাও"* → আর তোমার তথ্য গার্ডকে দিয়ে দেয় (`req.user`)।

---

## 📒 ৫. জাদুর খাতা = **Redis (session)**

কাউন্টার একটা খাতায় লিখে রাখে কে কে ভেতরে আছে:

```
খাতা (Redis):
  #7788 → রহিম   ✅ ভেতরে আছে
  #9900 → করিম   ✅ ভেতরে আছে
```

এক্সপার্ট প্রতিবার এই খাতা দেখে সিরিয়াল নম্বর আছে কিনা।

---

## 🚪 ৬. বেরিয়ে যাওয়া = **Logout**

তুমি বাড়ি যাওয়ার সময় বললে "আমি চলে যাচ্ছি"।

```
POST /auth/logout
```

কাউন্টার খাতা থেকে তোমার নাম **কেটে দেয়**:

```
খাতা (Redis):
  #7788 → রহিম   ❌ কেটে দেওয়া হলো!
```

এখন মজাটা দেখো — তোমার হাতে ব্যান্ড এখনো আছে (মেয়াদ শেষ হয়নি)। কিন্তু তুমি আবার রাইডে গেলে এক্সপার্ট খাতা দেখে বলবে:

> **"#7788 তো খাতায় নেই! এ নকল, ঢুকতে দিও না।"** ❌

👉 এই জন্যই Redis খাতা রাখা — logout করলেই ব্যান্ড সাথে সাথে অকেজো।

---

## 🔄 ৭. ব্যান্ড ছিঁড়ে গেলে = **Refresh**

Access ব্যান্ড (🎗️) ছোট, ১ দিনে নষ্ট হয়ে যায়। তখন তুমি Refresh ব্যান্ড (🔄) দেখাও:

```
POST /auth/refresh   { refreshToken }
```

কাউন্টার দেখে: *"ও, তোমার সিরিয়াল #7788 তো এখনো খাতায় আছে!"* → নতুন একটা Access ব্যান্ড দিয়ে দেয়। কাউন্টারে গিয়ে আবার পাসওয়ার্ড দিতে হয় না। 😎

---

## 🎬 পুরো গল্প এক নজরে

```
১. Login    → পাসওয়ার্ড দাও      → ব্যান্ড পাও 🎗️ + খাতায় নাম ওঠে 📒
২. রাইড     → ব্যান্ড দেখাও 🎗️     → গার্ড 💂 + এক্সপার্ট 🔍 চেক করে → ঢুকলে ✅
৩. Refresh  → পুরনো ছিঁড়লে 🔄    → নতুন ব্যান্ড পাও (পাসওয়ার্ড ছাড়াই)
৪. Logout   → "চলে যাচ্ছি" 🚪     → খাতা থেকে নাম কাটা ❌ → ব্যান্ড অকেজো
```

## 🧩 কোন চরিত্র কোন ফাইল

| গল্পের চরিত্র | আসল ফাইল |
|--------------|----------|
| 🎟️ টিকিট কাউন্টার | `auth.service.ts` |
| 💂 রাইডের গার্ড | `jwt-auth.guard.ts` |
| 🔍 ব্যান্ড-পরীক্ষক | `strategies/jwt.strategy.ts` |
| 📒 জাদুর খাতা | Redis (`session.util.ts` key বানায়) |
| 🎗️ হাতের ব্যান্ড | JWT token |
| 🚪 দরজা (কোন রাইডে কী লাগে) | `auth.controller.ts` |

> দুটো একসাথে মিললে তবেই রাইডে চড়তে পারবে!** 🎢
